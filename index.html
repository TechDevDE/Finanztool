Datenschutz & Local Storage

Sämtliche Berechnungen, Portfoliowerte und Haushaltsbucheinträge werden verschlüsselt im Local Storage deines eigenen Browsers gesichert. Es findet zu keinem Zeitpunkt eine Übertragung dieser privaten Finanzdaten an externe Server statt.

Zur Bereitstellung von Live-Kursen sowie zur Anzeige von Werbepartnern (Affiliate- und Referral-Links) werden gängige Web-Protokolle genutzt. Hierbei können IP-Adressen kurzzeitig an die Kurs-Dienstleister übertragen werden.
